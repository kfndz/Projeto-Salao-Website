# NilKely Cabeleireiro & Barbearia

Website institucional desenvolvido como **projeto final do curso de Desenvolvimento Front-End**, com o objetivo de aplicar na prática conceitos fundamentais de criação de interfaces web utilizando **HTML, CSS e JavaScript**.

---

## 📚 Sobre o projeto

O **NilKely Cabeleireiro & Barbearia** é um site simples que representa um salão de cabeleireiro e barbearia.  

O projeto foi desenvolvido com foco na prática de **estruturação de páginas, estilização de componentes, interações básicas com JavaScript e adaptação para diferentes dispositivos**.

A interface apresenta informações do salão, um carrossel de imagens do ambiente e uma seção de produtos exibidos em formato de cards.

---

## 🚀 Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript

---

## 🧩 Estrutura do site

### 🔝 Navbar
A barra de navegação contém:

- Logo **NK** (utilizando tag `h1`)
- Barra de pesquisa com ícone dentro do campo
- Links de navegação:
  - Produtos
  - Serviços
  - Sobre nós
  - Contato

---

### 🖼️ Seção principal

A página inicial apresenta:

- Título **NilKely Cabeleireiro & Barbearia**
- Um **carrossel de imagens** do salão
- Navegação com **setas para alternar entre as imagens**

O carrossel possui **4 a 5 imagens** exibindo o ambiente do estabelecimento.

---

### 🛍️ Seção de produtos

O site contém **4 cards de produtos**, incluindo:

- Kit Pomada de Cabelo
- Kit Shampoo
- Kit Shampoo + Máscara
- Kit Escova de Cabelo

Cada card possui:

- Imagem do produto
- Nome do produto
- **Efeito hover** ao passar o mouse

Ao clicar no produto, o usuário é direcionado para **outra página**, utilizando **JavaScript para navegação**, porém sem conteúdo detalhado cadastrado.

---

### 📍 Rodapé (Footer)

O rodapé contém:

- Endereço do estabelecimento
- Número de telefone
- Tag `address` com informações adicionais de contato

---

## 📱 Responsividade

O site foi posteriormente atualizado para possuir **layout responsivo**, adaptando a interface para diferentes tamanhos de tela utilizando **CSS e media queries**.
